Программа представляет собой многопоточный HTTP/1.1 веб-сервер, разработанный на уровне системных вызовов POSIX. Сервер предназначен для статического контента (HTML, CSS, изображений и бинарных файлов).

### 1. Архитектурное разделение по уровням

1. Сетевой транспорт: Строгая RAII-обёртка над файловыми дескрипторами POSIX. Предотвращает утечки ресурсов при исключениях. Сетевой слой управляет системными вызовами `socket()`, `bind()`, `listen()`, `accept()`.
2. Жизненный цикл и сигналы (`SignalWatcher`):  Идиоматичная для C++ реализация Graceful Shutdown без глобальных переменных и атомиков. Сигналы `SIGINT` и `SIGTERM` маскируются в главном потоке через `pthread_sigmask()` до старта серверной части, после чего фоновый поток `SignalWatcher` выполняет синхронный `sigwait()` и уведомляет сервер через `std::stop_source` / `std::stop_token`.
3. Протокольный парсер и MIME: Разбор входящих HTTP GET-запросов. Включает реестр MIME-типов для заполнения заголовка `Content-Type` (`text/html`, `text/css`, `image/png`, `image/jpeg` и др.).
4. Конкурентная обработка: Каждое входящее клиентское соединение передаётся в отдельный рабочий поток `std::jthread`. Реализовано поточно-безопасное чтение файлов в бинарном режиме и надёжная отправка данных через системный вызов `send()`.

### 2. Безопасность путей (Path Traversal Protection)

Сервер проверяет запрашиваемый URI на попытки выхода за пределы корневой директории `public/` (например, через последовательности `../` или абсолютные пути ОС):
* Запрашиваемый путь канонизируется через `std::filesystem::weakly_canonical()`.
* Выполняется проверка вхождения результирующего пути в базовый путь директории `public/`.
* При попытке выхода сервер возвращает ошибку `403 Forbidden` или `404 Not Found`.
