# Описание

| [Сборка ⟶](./BUILD.md) |
|------------------------|

Программа представляет собой итеративный DNS-резолвер на C++.
Он берёт на себя задачу *итерации*, посылая в запросах на DNS-сервера флаг `RD=0`, 
указывая на отсутствие необходимости в полном обходе дерева. 

Семантически процесс разделен на уровни:
1. **Сетевой уровень (`Socket`):** RAII-обертка над 
POSIX-сокетами, управляющая таймаутами и дескрипторами. 
Реализована строгая изоляция транспорта: 
сокет оперирует сырыми байтами и ничего не знает о протоколе DNS.
2. **Уровень бинарной сериализации (`BinaryBuffer`):** 
Преобразует структуры данных в сетевой формат RFC 1035 (Big-Endian). 
Реализует парсер сжатия доменных имен (DNS Name Compression)
через разыменование 14-битных указателей со смещением (`0xC0`).
3. **Уровень протокола (`DNSPacket`):** 
Моделирует пакет с заголовком и секциями: Question, Answer, Authority, Additional.
4. **Уровень логики (`Resolver`):** 
Координирует итеративные шаги, перебор пула серверов уровня при таймаутах,
сопоставление Glue-записей через хэш-таблицу и обработку алиасов CNAME.
