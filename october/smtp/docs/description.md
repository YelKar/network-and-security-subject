## Локальный запуск

Для локального запуска и тестирования использовалась библиотека python-aiosmtpd.
Он подходит для простой отладки без авторизации.
Позволяет запуск на **любом** порту.

## Запрос на smtp.yandex.ru и smtp.mail.ru

Для тестирования на реальном почтовом ящике.
Для подключения к нему требуется авторизация и передача данных по протоколу STARTTLS (библиотека OpenSSL).
Следовательно, были получены необходимые ключи.

Порт 25 не позволяет подключаться.
Поэтому используется порт 587, а в момент подключение отправляется мой email и полученный ранее ключ.
