## 2. DNS-запрос к домену google.com.
DNS работает по порту 53.
Следовательно нам нужно просто отфильтровать по нему.
```
❯ tcpdump -r capture.pcap -n 'port 53' | grep "google.com"  
reading from file capture.pcap, link-type EN10MB (Ethernet), snapshot length 262144  
00:52:53.998635 IP 10.103.146.78.56235 > 10.103.146.158.53: 63018+ A? google.com. (28)  
00:52:53.998647 IP 10.103.146.78.55131 > 10.103.146.158.53: 39032+ AAAA? google.com. (28)
```
Так же можно попробовать отфильтровать контенту.
Устройство DNS пакета:
* IP-заголовок занимает 20 байт. Дальше данные UDP.
* UDP-заголовок — 8 байт
* DNS-заголовок — 12 байт
* Далее передаётся имя домена по следующему приципу:
	1. Байт s с размером домена уровня n
	2. Домен уровня n размера s
	* Байт s2 с размером домена уровня n - 1
	* Домен уровня n -  1  размера s2
	* ...
	* Байт sn с размером ломена уровня 1
	* Домен уровня sn.

То есть для google.com:
* 20-й байт: 6
* 21-26 байты: google
* 27-й байт: 3
* 28-30 байты: com
